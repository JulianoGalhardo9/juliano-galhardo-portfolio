Este repositório contém o código-fonte do meu portfólio pessoal — um espaço onde centralizo minha trajetória acadêmica, habilidades técnicas e os projetos de maior impacto que desenvolvi.

Sou graduando em **Engenharia de Software**, com foco no ecossistema **backend**, **sistemas distribuídos** e **computação em nuvem**. Busco minha primeira oportunidade de estágio para colaborar com times de engenharia no desenvolvimento de APIs escaláveis, aplicando boas práticas de arquitetura e design de código.

## ⚡ Rodando Localmente

Siga os passos abaixo para executar o projeto na sua máquina:

```bash
# 1. Clone o repositório
git clone https://github.com/JulianoGalhardo9/seu-repositorio.git

# 2. Entre no diretório
cd seu-repositorio

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev
```

Acesse **`http://localhost:3000`** (ou a porta indicada no terminal) no seu navegador.

## 🚢 Deploy

O deploy é realizado de forma **contínua via [Vercel](https://vercel.com)**. Cada `git push` na branch principal dispara automaticamente uma nova build, garantindo que o portfólio esteja sempre atualizado.
